## 🆘 Troubleshooting

### Problem: "Sync Failed" Message
**Solution:** Check your internet connection. Close metagrid, restart it, and try again. If the problem persists, check if your firewall is blocking the app – allow metagrid through Windows Defender Firewall.

### Problem: Dota 2 Doesn't Show Updated Grid
**Solution:** Make sure Dota 2 is fully closed before running metagrid. Open metagrid, wait for the sync to complete, then launch Dota 2.

### Problem: Antivirus Warning
**Solution:** Some antivirus programs may flag new applications. This is a false positive. Add metagrid to your antivirus exceptions list, or temporarily disable real-time protection while downloading and running it.

### Problem: App Won't Open
**Solution:** Right-click the metagrid file, select "Run as administrator," and try again. If it still won't open, restart your computer and retry.
